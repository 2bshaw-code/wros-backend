# WROS Backend

Node.js / Express backend for the WROS retail operations platform.

## Stack

- **Runtime**: Node.js 20
- **Framework**: Express 5
- **Database**: MongoDB (via Mongoose)
- **Auth**: JWT (access + refresh tokens)
- **Payments**: Stripe
- **Messaging**: WhatsApp Cloud API

---

## Local Development

```bash
cp .env.example .env
# Fill in required values in .env
npm install
npm run dev
```

Server starts at `http://localhost:3000`.

---

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `NODE_ENV` | Yes | `development` or `production` |
| `PORT` | No | Server port (default `3000`) |
| `MONGO_URI_PROD` | Yes (prod) | MongoDB Atlas connection string |
| `JWT_SECRET` | Yes | Secret for access token signing |
| `JWT_REFRESH_SECRET` | Yes | Secret for refresh token signing |
| `STRIPE_SECRET_KEY` | Yes | Stripe secret key |
| `STRIPE_WEBHOOK_SECRET` | Yes | Stripe webhook signing secret |
| `WHATSAPP_VERIFY_TOKEN` | Yes | Meta webhook verify token |
| `WHATSAPP_ACCESS_TOKEN` | Yes | WhatsApp Cloud API access token |
| `WHATSAPP_PHONE_NUMBER_ID` | Yes | WhatsApp phone number ID |
| `WHATSAPP_BUSINESS_ID` | Yes | WhatsApp Business Account ID |
| `WHATSAPP_APP_SECRET` | No | WhatsApp App Secret (for signature verification) |
| `HOSTING_URL` | Yes | Public base URL (e.g. `https://api.wros.co.uk`) |
| `CONSOLE_URL` | Yes | Console URL (e.g. `https://console.wros.co.uk`) |
| `FRONTEND_URL` | Yes | Frontend URL (e.g. `https://console.wros.co.uk`) |
| `API_URL` | Yes | API base URL (e.g. `https://api.wros.co.uk/api`) |
| `CRM_ENABLED` | No | Enable CRM module (default `true`) |
| `ORDERS_ENABLED` | No | Enable Orders module (default `true`) |
| `INVOICES_ENABLED` | No | Enable Invoices module (default `true`) |
| `DELIVERY_ENABLED` | No | Enable Delivery module (default `true`) |
| `FAULTS_ENABLED` | No | Enable Fault Reports module (default `true`) |
| `DOWNLOADS_ENABLED` | No | Enable Downloads module (default `true`) |

## Render Deployment

### Web Service Settings

| Setting | Value |
|---|---|
| **Build Command** | `npm install --omit=dev` |
| **Start Command** | `node server.js` |
| **Node Version** | `20` |
| **Health Check Path** | `/api/health` |

### Steps

1. Connect the `2bshaw-code/wros-backend` GitHub repository in Render.
2. Create a new **Web Service** (or use the `render.yaml` blueprint).
3. Set all required environment variables listed above in the Render dashboard under **Environment**.
4. Deploy — Render will run the build command and then start the server.

> **Tip**: `JWT_SECRET` and `JWT_REFRESH_SECRET` can be auto-generated by Render using the `generateValue` option in `render.yaml`.

## Key API Routes

All routes are prefixed with `/api`:

| Method | Path | Description |
|---|---|---|
| `POST` | `/auth/register` | Register admin user |
| `POST` | `/auth/login` | Login |
| `GET` | `/auth/me` | Get current user |
| `GET` | `/health` | Health check |
| `GET` | `/status` | Service status |
| `GET` | `/products` | List products |
| `POST` | `/products` | Create product |
| `GET` | `/orders` | List orders |
| `POST` | `/orders` | Create order |
| `GET` | `/customers` | List customers |
| `POST` | `/ai/ask` | Ask BOB assistant |
| `GET` | `/reports/summary` | Sales summary |
